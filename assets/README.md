# Assets

Original art, audio and fonts go here. Empty for now — the prototype draws
colored rectangles.

Before adding anything, read `docs/ART_AND_IP.md`. Every asset must be
original (or commercially licensed) and recorded in `assets/CREDITS.md`
with its author/source and license.

Planned structure:

```
assets/
  sprites/    player, enemies, items (PNG, 16x16 grid)
  tiles/      tilesets per theme
  audio/sfx/  sound effects (WAV/OGG)
  audio/music/
  fonts/
  CREDITS.md
```
